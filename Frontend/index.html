HOW IT WORKS
1
Present proof hash

Use the hash returned when the credential was issued.

2
ATLAS checks the record

The API checks the database and reads the AtlasRegistry smart contract directly.

3
Receive a result

Result is verified, invalid, or revoked.

Local dev chain

Proofs are on a local Hardhat test chain, not a public network. The on-chain check proves the hash was logged and whether it was revoked.
